# Marketing system instructions

This system supports Echo's website, the marketing side of Design Studio's example product. Read [Echo brand](context/brand.md) for visual direction and [Marketing library](context/library.md) for the imported subset and adaptation choices. Follow the repository's platform working context.

Use Marketing’s shadcn/Base UI components and `lucide-react` icons. Compose page sections inside the prototype. Do not import Platform or Product components, or expand the token inventory to the upstream catalog. Keep Base UI popups in the shared themed portal container.

Follow [Marketing design](context/design.md) when composing or revising marketing pages and project artifacts.
